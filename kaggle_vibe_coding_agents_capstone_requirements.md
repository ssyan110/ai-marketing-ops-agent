## 1. Executive Summary

The **AI Agents: Intensive Vibe Coding Capstone Project** is the final hands-on project for the Kaggle + Google **5-Day AI Agents: Intensive Vibe Coding Course**.

The capstone asks participants to **put course learning into action by building an AI agent that solves a real-world problem, helps people, or improves everyday living**.

A strong submission should demonstrate:

| Area | What to Show |
|---|---|
| Real-world value | The agent solves a clear, practical problem for a target user. |
| Agentic behavior | The system does more than simple chat; it can reason, use tools, execute steps, or coordinate workflow. |
| Vibe coding workflow | Natural language is used as a primary interface for building, controlling, or improving the system. |
| Technical implementation | The project has working code, clear architecture, and reproducible setup. |
| Reliability | The agent includes evaluation, testing, error handling, or guardrails. |
| Communication | The project is explained clearly through a Kaggle Writeup, video demo, codebase, and project/demo link. |

## 3. Course Learning Themes to Demonstrate

According to the official Google announcement, the course focuses on building AI agents from foundational concepts to production-ready systems, especially through **vibe coding**.

| Theme | Meaning for Capstone Project |
|---|---|
| Vibe coding workflows | Natural language becomes the primary programming/control interface. Your project should show how prompts or natural language instructions help build, guide, or operate the agent. |
| Tool and API integration | The agent should use external tools, APIs, code execution, search, files, databases, or other services where useful. |
| “10x agents” | The agent should automate a meaningful workflow and create leverage beyond a simple chatbot. |
| Multi-agent systems / interoperability | Optional but valuable: show multiple agents/subagents or agent-to-agent coordination. |
| Memory and context | The agent should preserve relevant state, user preferences, documents, conversation history, or task context when useful. |
| Quality and testing | Include tests, evals, validation checks, or example test cases showing the agent works reliably. |
| Guardrails and security | Include safety constraints, input validation, privacy controls, permission boundaries, or failure-mode handling. |
| Production readiness | Show deployment, reproducible setup, logging, monitoring, scalability thinking, or observability where possible. |

## 8. Possible Capstone Project Direction for Adam Yan AI

Because your goal is to build practical AI-agent content for Vietnamese professionals, the best-fit capstone direction is:

## Recommended Project: AI Marketing Ops Agent for Vietnamese Office Workers and Small Businesses

### Problem

Vietnamese office workers, marketers, and small business owners often need to create useful content quickly, but they struggle with research, structuring ideas, writing posts, creating visuals/scripts, and planning distribution.

### Agent Solution

An AI agent that turns one business idea or pain point into a complete marketing workflow:

| Step | Agent Output |
|---|---|
| 1. Understand user goal | Target audience, business type, content objective |
| 2. Research pain points | Finds practical angles and user problems |
| 3. Generate content strategy | LinkedIn carousel outline, short video script, post caption |
| 4. Produce assets | Draft carousel copy, hook, CTA, demo script |
| 5. Quality check | Checks clarity, usefulness, hallucination risk, tone, and actionability |
| 6. Distribution plan | Suggested posting schedule and repurposing plan |
| 7. Memory | Stores brand voice, audience, preferred formats, and previous topics |

### Why This Fits the Competition

| Requirement | How This Project Satisfies It |
|---|---|
| Solves real-world problem | Helps professionals create useful AI-powered business content faster. |
| Agentic workflow | Multi-step process from idea → research → content → QA → distribution. |
| Tool use | Can use search, document input, content templates, database, or scheduling APIs. |
| Memory | Remembers brand voice, audience, past posts, and content preferences. |
| Evaluation | Can evaluate output using a content-quality rubric. |
| Guardrails | Avoids false claims, checks source reliability, flags weak content. |
| Demo-friendly | Easy to show in a 3–5 minute video. |
| Portfolio value | Useful for Adam Yan AI, LinkedIn, and future consulting/services. |
